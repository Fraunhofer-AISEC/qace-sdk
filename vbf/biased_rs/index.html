Biased Function via Rejection Sampling¶

qace.vbf._biased_rs ¶

Biased vectorial Boolean function generation via rejection sampling.

Provides utilities for generating random vectorial Boolean functions with a prescribed bias for a specific mask pair using rejection sampling.

BiasedFunctionRS(m, n, alpha, beta, p, seed=12345) ¶

Bases: VectorialBooleanFunctionFull

A vectorial Boolean function with a prescribed bias generated via rejection sampling.

Uses a rejection sampling strategy to produce a function with a specific bias for a given mask pair (alpha, beta).

Attributes:
  • alpha –

    Input mask encoded as an integer.

  • beta –

    Output mask encoded as an integer.

  • seed –

    Random seed used for reproducible function generation.

  • p –

    The prescribed bias for the mask pair (alpha, beta).

Initializes the biased function by generating it via rejection sampling.

Parameters:
  • m (int) –

    Input dimension (number of input bits).

  • n (int) –

    Output dimension (number of output bits).

  • alpha (int) –

    Input mask encoded as an m-bit integer.

  • beta (int) –

    Output mask encoded as an n-bit integer.

  • p (float) –

    Desired bias for the mask pair (alpha, beta).

    Random seed for reproducible generation.

def __init__(
    self, m: int, n: int, alpha: int, beta: int, p: float, seed: int = 12345
):
    """Initializes the biased function by generating it via rejection sampling.

    Args:
        m: Input dimension (number of input bits).
        n: Output dimension (number of output bits).
        alpha: Input mask encoded as an m-bit integer.
        beta: Output mask encoded as an n-bit integer.
        p: Desired bias for the mask pair (alpha, beta).
        seed: Random seed for reproducible generation.
    """
    self.alpha = alpha
    self.beta = beta
    self.seed = seed
    self.p = p

    # Save the rng state to make it independent of the seed used in this class
    state_backup = random.getstate()
    random.seed(self.seed)

    lookup_table = _biased_f_rejection_sampling(self.p, m, n, self.alpha, self.beta)

    # Restore the rng state
    random.setstate(state_backup)

    super().__init__(lambda x: lookup_table[x], m, n)
