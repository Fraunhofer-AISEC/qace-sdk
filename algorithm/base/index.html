Base Module¶

qace.algorithm._base ¶

Module defining the abstract base class for quantum algorithms.

This module provides the QuantumAlgorithm abstract base class and the AlgorithmResult dataclass. Concrete algorithm implementations should subclass QuantumAlgorithm and implement the build_circuit method.

AlgorithmResult(execution_result, metadata=dict()) dataclass ¶

Result of a quantum algorithm execution.

Abstract base class for all quantum algorithms.
